# 🎬 KannadaOTT Finder

> Find high-rated **Kannada Originals** and **Kannada Dubbed** movies on Indian OTTs — instantly.

A personal movie discovery platform tailored for **JioHotstar, Zee5, SonyLIV, and JioCinema** with direct links to watch.

---

## ✨ Features

- 🌟 **ಕನ್ನಡ Originals**: Browse original Kannada movies (777 Charlie, Sapta Sagaradaache Ello, Hostel Hudugaru, Daredevil Musthafa, Ratnan Prapancha, Badava Rascal, Toby, etc.).
- 🎙️ **ಕನ್ನಡ Dubbed Hits**: High-rated Hindi, Malayalam, Tamil, and Telugu releases with Kannada audio (12th Fail, Premalu, Manjummel Boys, Sita Ramam, Gargi, Sam Bahadur, Hanu-Man, Por Thozhil, etc.).
- 🚫 **Zero Paid Waste**: Excludes Netflix and Prime Video per preference — focused on Indian OTTs (**JioHotstar, Zee5, SonyLIV, JioCinema**).
- 🎭 **Curated Genres**: Prioritizes **Comedy, Family, Feel-Good, and Realistic Drama**. Excluded unrealistic spy/war fighter movies.
- 🔗 **Direct OTT Deep Linking**: Click "Watch on Hotstar / Zee5 / SonyLIV / JioCinema" to go directly to the title.
- 📱📺 **Mobile & Smart TV Friendly**: 10-foot UI with high-contrast D-pad keyboard focus rings.
- ⚡ **Zero Setup / No API Key Needed**: Works 100% out of the box with built-in catalog, plus optional live TMDB fallback if an API key is provided later.

---

## 📺 Using on Smart TV

1. Ensure PC and Smart TV are on the same Wi-Fi.
2. Open the browser app on your Smart TV.
3. Type: `http://192.168.29.149:3000`
4. Use TV remote arrow keys (D-pad) to scroll rows and movies.
5. Press **OK / Enter** on a movie card to open details and press **Watch Now** to launch the OTT platform.
